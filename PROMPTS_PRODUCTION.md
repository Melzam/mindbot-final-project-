# Документация по промтам

## 1. Психологический совет — `/daily_insight`

### Цель
Дать пользователю короткий, безопасный и поддерживающий совет в рамках выбранного направления.

### Принципы
- тёплый тон
- без диагнозов
- без медицинских назначений
- без обещаний результата
- один понятный практический шаг

### Структура
1. Короткий заход
2. Простое объяснение
3. Практика на 3–7 минут
4. Поддерживающее завершение

---

## 2. Практика осознанности — `/mindfulness_exercise`

### Цель
Дать мягкую короткую практику на 3–5 минут.

### Принципы
- бережная подача
- простые шаги
- без жёстких инструкций
- без медицинских формулировок

### Структура
1. Подготовка
2. 5–7 шагов
3. Завершение
4. Что заметить

---

## 3. Иллюстрация эмоции — `/emotion_card`

### Цель
Сгенерировать абстрактную визуализацию, которая помогает передать эмоциональное состояние через образ.

### Принципы
- без текста на изображении
- спокойная композиция
- современный стиль
- визуальная мягкость

### Используемый смысловой шаблон
- abstract emotional illustration
- psychological self-reflection
- выбранное пользователем направление
- soft expressive colors
- modern editorial style
- calming composition
- no text

---

## 4. Ежедневная рассылка

### Цель
Присылать пользователю короткий утренний поддерживающий инсайт в 10:00 по Москве.

### Принципы
- до 200 символов
- без клише
- без пафоса
- без тяжёлых формулировок
- мягкий психологический тон
